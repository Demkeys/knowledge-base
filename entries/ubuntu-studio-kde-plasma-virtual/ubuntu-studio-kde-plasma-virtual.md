FutureRef:
If using Ubuntu Studio (KDE Plasma Desktop Environment), if Virtual Desktops (VDs) aren't working by default, you might need to go into system settings and create additional VDs. To do this, go to System Settings > Workspace Behavior > Virtual Desktops. If you only see one desktop in the list, there's your problem. Create more, hit Apply and then you should be able to move windows to other VDs and also switch to other VDs.
